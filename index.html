Nhập JSON Hàng loạt

Dán danh sách từ vựng (Array) hoặc Object JSON vào đây.

Xem hướng dẫn định dạng JSON

Bắt buộc phải có trường "word". Bạn không cần nhập đủ tất cả các trường (có thể bỏ trống những trường không cần thiết).

Ví dụ định dạng Mảng (Array): 
[
  {
    "word": "apple",
    "ipa": "/ˈæp.əl/",
    "meaning": "quả táo",
    "image": "https://link-to-image...",
    "exampleEn": "I eat an *apple* every day.",
    "exampleVi": "Tôi ăn một *quả táo* mỗi ngày."
  }
]

Danh sách khóa (key): word, ipa, meaning, image, exampleEn, exampleVi, audioWord, audioExample.
