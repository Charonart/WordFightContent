Nhập JSON Hàng loạt

Dán gói trọn bộ (gồm Banner + từ vựng) hoặc danh sách từ vựng JSON vào đây.

Xem hướng dẫn định dạng JSON chi tiết (Phương Án B)

Hỗ trợ định dạng Gói Trọn Bộ (Phương Án B) gồm cả thẻ bìa banner và danh sách từ vựng vocabularies (hoặc dạng mảng Array truyền thống).

Trường trong "banner" Loại Ý nghĩa / Mô tả
openingText Tùy chọn Phần mở đầu ở trên (VD: "Bẻ khóa từ vựng\ntiếng Anh với")
subject Tùy chọn Chủ đề từ vựng ở dưới, in hoa nổi bật (VD: "GREEK ROOT")
Trường trong "vocabularies" Loại Ý nghĩa / Mô tả
word Bắt buộc Từ vựng tiếng Anh (VD: "alive")
wordType Tùy chọn Loại từ (VD: "n", "adj", "v", "adv")
ipa Tùy chọn Phiên âm quốc tế (VD: "/əˈlaɪv/")
meaning Tùy chọn Nghĩa tiếng Việt (VD: "còn sống, hoạt động")
image Tùy chọn Link ảnh URL hoặc Data URL base64
exampleEn Tùy chọn Ví dụ tiếng Anh (dùng *từ* để in đậm/gạch chân)
exampleVi Tùy chọn Dịch ví dụ tiếng Việt (dùng *từ* để in đậm)
explain Tùy chọn Giải thích thêm, ghi chú ngữ cảnh (dùng \n để xuống dòng)
cefrLevel Tùy chọn Trình độ CEFR (VD: "A1", "A2", "B1", "B2", "C1", "C2")
Ví dụ chuẩn Phương Án B (Gói Trọn Bộ): 
{
  "banner": {
    "openingText": "Bẻ khóa từ vựng\ntiếng Anh với",
    "subject": "GREEK ROOT"
  },
  "vocabularies": [
    {
      "word": "embark",
      "wordType": "v",
      "ipa": "/ɪmˈbɑːk/",
      "meaning": "bắt đầu, dấn thân vào",
      "image": "",
      "exampleEn": "She decided to *embark* on a new career.",
      "exampleVi": "Cô ấy quyết định *bắt đầu* một sự nghiệp mới.",
      "explain": "embark on sth: bắt đầu việc gì mới mẻ.",
      "cefrLevel": "B2"
    }
  ]
}
